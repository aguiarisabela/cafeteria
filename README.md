Um site moderno e responsivo para uma cafeteria fictícia, desenvolvido com HTML, CSS e JavaScript puro. O projeto apresenta um design acolhedor e funcional, perfeito para estabelecimentos que buscam presença digital.

## 📋 Sobre o Projeto

O **Bom Café** é um website completo que simula a presença online de uma cafeteria, oferecendo uma experiência visual agradável e navegação intuitiva. O site foi desenvolvido com foco em responsividade e acessibilidade, garantindo uma ótima experiência em dispositivos móveis e desktops.

## ✨ Funcionalidades

- **🏠 Seção de Destaque**: Apresentação principal com chamada para ação
- **📖 Sobre Nós**: História e propósito da cafeteria com links para redes sociais
- **🍽️ Cardápio**: Exibição de produtos com imagens e descrições
- **💬 Depoimentos**: Carrossel interativo com feedback de clientes
- **🖼️ Galeria**: Showcase visual dos produtos e ambiente
- **📞 Contato**: Formulário funcional e informações de contato
- **📱 Menu Mobile**: Navegação adaptada para dispositivos móveis
- **🎨 Design Responsivo**: Layout otimizado para todas as telas

## 🎯 Destaques Técnicos

### Carrossel de Depoimentos
O projeto conta com um carrossel personalizado desenvolvido do zero com JavaScript puro, apresentando:

- ✅ Scroll infinito (loop contínuo)
- ✅ Autoplay com pausar ao hover
- ✅ Navegação por arrastar (drag & drop)
- ✅ Suporte touch para dispositivos móveis
- ✅ Botões de navegação lateral
- ✅ Transições suaves

### Menu Responsivo
- Menu hambúrguer para mobile
- Animações de transição suaves
- Overlay com efeito blur
- Fechamento automático ao clicar nos links

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica
- **CSS3**: Estilização moderna com variáveis CSS, Flexbox e Grid
- **JavaScript (Vanilla)**: Interatividade sem dependências
- **Font Awesome**: Ícones vetoriais
- **Google Fonts**: Tipografia (Poppins e Miniver)

## 🚀 Como Executar

1. **Clone o repositório**
```bash
git clone https://github.com/aguiarisabela/bom-cafe.git
```

2. **Navegue até a pasta do projeto**
```bash
cd bom-cafe
```

3. **Abra o arquivo `index.html`**
   - Dê um duplo clique no arquivo, ou
   - Use uma extensão como Live Server no VS Code

## 📱 Responsividade

O site é totalmente responsivo com breakpoints otimizados para:

- 📱 Mobile: até 640px
- 📱 Tablet: 641px - 900px
- 💻 Tablet Grande: 901px - 1024px
- 🖥️ Desktop: 1025px+
